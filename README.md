# platform-demo-backstage-plugin-policies

Backstage plugin for the platform-demo portal: a **Policies** tab per service (Kyverno findings of its objects) and a **Policies**
page (the installed admission policies and what each does).

| Package | Path |
|---|---|
| `@platform-boutique/backstage-plugin-policies` (frontend) | `plugins/policies` |
| `@platform-boutique/backstage-plugin-policies-backend` | `plugins/policies-backend` |

Documentation: `docs/` (rendered in the portal). `yarn install && yarn tsc && yarn build` to develop.
